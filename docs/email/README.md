## Activation

1. Identify the current email provider and the authorised domain administrator. Inspect existing mailboxes and domain records before making changes.
2. Retain any existing `info` account. Create only missing addresses, using separate or shared mailboxes according to the provider and staff access requirements. The CSV in this folder is an account specification, not a provider-specific import file.
3. Assign staff through the provider's normal access controls. Set passwords and recovery options privately in that service. Do not place credentials in this repository or a chat message.
4. Obtain domain verification, MX, SPF and DKIM values from the selected provider. Preserve existing senders and working mail services. No DNS values have been guessed or changed here. Review the provider's DMARC setup with the domain administrator.
5. Configure the display names and signatures below. Automatic replies are optional and remain disabled until the mailbox is receiving messages correctly.
6. Test each address using an authorised external account: receive a message, reply, check the sender address, and inspect the message's authentication results. Test allowed staff access. The website work did not send any test email.
7. Once confirmed, add only verified addresses to the site's contact page and relevant service sections. Keep candidate documents within the authenticated application process; email replies should direct users to that process when suitable.
