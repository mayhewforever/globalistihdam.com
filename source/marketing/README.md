# Homepage slideshow source

These app files update source revision a088d4890976d47f6be6177ec7ed856a48e2ac1d. Copy them into app/ of that source checkout. The five globalistihdam-slide-*.webp assets belong in public/. Run node scripts/export-github-pages.mjs to regenerate the public output. The current public build is included at the repository root. This task does not deploy or change access to the private application portal.

The carousel respects reduced motion, pauses on focus and pointer hover, and stops automatic rotation after manual slide navigation. All slides have translated captions and direct service links.
